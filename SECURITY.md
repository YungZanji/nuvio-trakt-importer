# Security Policy

## Supported version

Security fixes are applied to the latest version on the `main` branch and the current GitHub Pages deployment.

## Reporting a vulnerability

Do not include a Trakt export, Nuvio token, approval code, account email, backup, audit report, or viewing data in a public issue.

Use the repository's **Security** tab to submit a private vulnerability report when private vulnerability reporting is enabled. For a non-sensitive bug, open a normal GitHub issue with reproduction steps that use synthetic data.

## Security boundary

This project protects application data from the project operator by keeping processing in the browser. It cannot control data handling by Nuvio, Cinemeta, GitHub Pages, the browser, browser extensions, the operating system, or a compromised device.
