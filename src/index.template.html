Resolve artwork and exact resume times

Trakt exports playback as a percentage, while Nuvio Sync stores milliseconds. The lookup converts each percentage using the title or episode runtime and fills watchlist artwork.

The importer never saves this token. It is held only for this lookup, sent directly from your browser to TMDB, then cleared. Open your TMDB API settings.

Metadata fallback order

1. TMDB, recommended: posters, backgrounds, metadata, and runtime using your own read token. 2. Cinemeta: metadata/runtime fallback. MetaHub artwork returned by Cinemeta is intentionally rejected, so Cinemeta-only mode can leave some posters blank. 3. Manual runtime: only when neither provider can resolve runtime.

Runtime needed

The metadata providers could not resolve these runtimes. Enter the runtime in minutes, or use a clearly marked estimate.
