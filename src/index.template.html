Resolve artwork and exact resume times

Trakt exports playback as a percentage, while Nuvio Sync stores milliseconds. The lookup converts each percentage using the title or episode runtime and fills watchlist artwork.

The importer never saves this token. It is held only for this lookup, sent directly from your browser to TMDB as the authorization header, then cleared from the page when the lookup finishes. It is never sent to GitHub, Nuvio, Cinemeta, or the project operator. How to get a TMDB read token.

Metadata fallback order

1. TMDB, recommended: posters, backgrounds, metadata, and title/episode runtime using your own read token. 2. Cinemeta: metadata/runtime fallback when TMDB is not used or cannot resolve an item. Cinemeta commonly references MetaHub artwork, which this importer intentionally rejects because those poster URLs have failed for some Nuvio users. That means Cinemeta-only mode can leave some posters blank. 3. Manual runtime: only when neither provider can resolve the runtime. MetaHub artwork is never saved into Nuvio.
