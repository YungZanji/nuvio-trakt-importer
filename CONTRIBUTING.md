# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Run `npm ci`, `npm test`, and `npm run build`.
3. Do not commit real Trakt exports, Nuvio tokens, backups, audit files, approval codes, or personal viewing data.
4. Keep the app static and browser-only. New network origins, storage APIs, analytics, telemetry, service workers, or server-side processing require explicit privacy review and documentation.
5. Open a pull request explaining the behavior and privacy impact.

Tests and examples must use synthetic data.
